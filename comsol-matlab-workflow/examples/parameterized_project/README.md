# 参数化项目模板（PENDING / 未运行）

整体复制本目录到独立项目。唯一参数编辑入口config/model_config.m：L梁长、h梁高、x0/y0位置，单位m；L/h正、位置有限。area_tol相对误差、bbox_tol单位m，都是数值控制而非设计参数；默认值和元数据只在配置中维护。派生面积自动计算，不手工编辑。
在已连接COMSOL5.6的R2023a窗口，进入新项目src，然后执行 `run_model('新项目绝对路径')`。不在全局Skill目录内运行输出，不新开Batch/Server。
主函数每次自动读配置副本→校验→派生→全局参数同步回读→唯一新模型→实际几何验证→新MPH/CSV/PNG/参数JSON和源码副本；创建新的output/run_时间_UUID，不覆盖旧文件。示例仅几何，不创建材料/网格/Study或求解。
改L/h/位置必须重建几何，科研模型还要更新相关选择、材料区、网格和解；本示例每次新建模型，不将旧解复用。离散Polygon需重算坐标，不只改Global Definitions。已有MPH沿用先复制/加载/检查依赖的流程，不由本示例无条件自动修改。
另获批准后CaseA运行当前配置，CaseB只改L再运行同一主程序，独立检查MPH实际尺寸/面积/厚度与快照和同步；本轮不执行。直边坐标面积不代表原生测量精度修复，不用于曲边。实际参数变更传播仍PENDING。
