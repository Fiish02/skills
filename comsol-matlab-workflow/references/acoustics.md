# 声学与声固耦合研究流程

压力声学、声固耦合、辐射、SPL、声强、声功率、远场、PML均PENDING运行。按5.6 Acoustics手册核对模块、维度、Physics/Multiphysics类型与属性，不能猜acpr/solid/coupling tag。通过analysis_workflow.m回调装配实际方案。

明确介质密度/声速/损耗、频率、背景/总场/散射场、结构界面位移法向与声学压力/法向速度；不要擅自替换边界。SPL需指定参考压力、峰值/RMS和复幅值约定；声强/功率需核对共轭、法向和积分域；远场需核对变量、辐射边界与观测坐标。PML是需专门验证的区域/映射和网格方案，不是任意外边界的替代。
网格依据最高频率下相关介质/结构波长、单元阶次与薄层尺度，再做网格收敛；不固定通用每波长单元数。检查辐射域/PML厚度与距离敏感性、能量平衡、耦合界面和基准；有限值或彩色图不足以通过。
