# COMSOL–MATLAB 项目规则

- 唯一默认目标为 COMSOL 5.6.0.280、MATLAB R2023a Update 8；以 Windows 执行主机为准。Mac 仅可作为远程客户端，Windows 命令必须在 Windows 主机执行。
- 按全局 Skill 的 references/global_scope.md 读取共享知识库；当前项目的适用 AGENTS.md 与用户授权另行遵守。
- 先查本机 5.6 官方帮助，其次官方 5.6 网页；MATLAB 查 R2023a 文档。其他版本 API 必须逐项核实，找不到依据就标待验证。
- 用户已确认现有 COMSOL with MATLAB 连接可用。复用现有方式；不重装、不重新配置，不为初始化 Skill 重复兼容性测试。
- 修改模型前检查组件、参数、几何、材料、物理特征与选择、网格、Study、Solver 和 Results；优先复用现有结构。
- 原始 MPH 永不覆盖；加载运行目录中的副本，保存时必须明确新路径。原始 MATLAB 代码修改前备份或使用 Git。
- 对研究假设、本构关系、参数/载荷/边界、接触约束、网格策略、求解器设置和评价方法的新增选择或改变，先与用户讨论。已有明确授权可继续执行，不重复确认。
- 每次执行使用独立运行目录，保存输入与代码快照、完整日志、状态和验证结果；退出码为 0 不等于科研结果通过。
- 对结果检查求解完成状态、变量、有限值、单位、维度与物理验收标准；缺少标准时不能自行编造容差。
- 不擅自修改原 Preferences、pathdef.m、注册表、持久环境变量、许可证或防火墙，不删除已有模型、数据、日志。
- 管理员权限、许可配置或服务网络变化须先说明具体操作与影响，等待明确批准；密码和许可密钥不进入脚本、聊天或日志。
- 常规代码修复、数据处理和日志分析自主完成；改变物理模型或可能影响研究结论的取舍必须讨论。
- 失败时读完整日志，按阶段定位，不通过改变物理设置掩盖编程错误。
- 区分用户事实、官方文档、实测、推断与假设。知识库保留证据和适用版本；只有可复核的成功验证进入 validated_solutions.md。
