# 建模、求解与结果验收

## 修改前检查清单

记录模型文件/哈希、版本、组件 tags、参数表达式与单位、Geometry 特征、Materials 分配、Physics 特征类型/属性和 Selection、Mesh 特征与质量、Study 步骤、挂接 Solver、Results datasets 与解编号。可用 5.6 JavaDoc list.tags()、getType、getAllowedPropertyValues 辅助核实；具体接口依据 api reference。只看节点名称不足以判断边界条件。

原始 MPH 只复制，不直接保存回原路径。加载副本仍会在服务器创建模型对象，需使用唯一 tag；已有 tags 不能覆盖。几何变化后重查边界选择和材料分配，参数变更后明确需重建的依赖与解的有效性。

## 先讨论的研究选择

维度与对称性、本构关系、阻尼、接触、边界、载荷、网格尺度/阶次、频率或时间范围、特征值搜索、求解器/收敛、评价方法与误差阈值由研究需求确定。不得为了消除异常自动更换物理条件、放宽容差或删除困难参数点。

## 不同分析的验收

| 分析 | 至少检查 | 不可预设 |
|---|---|---|
| 模态 | 模态数、频率单位、刚体/重复模态、复频率、振型与归一化 | 所有特征值必须为正或所有频率纯实 |
| 频域/声学 | 频率与参数索引、复幅值/相位、单位、边界与共振分辨率、能量/功率或基准比较 | 幅值、RMS 与瞬时实部可互换 |
| 瞬态 | 时间单位、输出时刻/步长、初值、稳定性、守恒与采样 | 只有最后时刻有限就通过 |
| 参数扫描/优化 | 每点实际参数、求解状态、解与指标匹配、失败点保留、可重现性 | 复用上一点解一定有效，或失败点可以记零 |

验收至少有求解完成证据、变量存在、NaN/Inf、单位、数据维度和用户定义的物理/误差标准。isEmpty=false 不能排除旧解；结果图成功也不能证明计算正确。没有标准则 COMPLETED_UNVALIDATED。

Study.run() 和 Solver.runAll() 的责任不同；前者可能生成求解器，后者运行既有序列。使用已有手工 Solver 时先讨论采用 runNoGen 还是明确运行序列，不将自动生成默认 Solver 作为错误修复。

示例只演示已核实的对象关系；不新建完整物理模型，不预置材料、网格尺寸或求解参数。每个示例的 cfg/参数需来自实际模型检查。
